# 🏢 Test Company — лендинг дизайн-агентства

Одностраничный сайт-визитка дизайн-агентства на Next.js. Хиро-секция, бегущая строка с логотипами клиентов, блок кейсов, услуги, футер с контактами.

## 🌐 Демо

👉 https://test-company-umber.vercel.app

## 🛠 Технологии

- Next.js
- React
- Tailwind CSS
- Деплой: Vercel

## ⚙️ Функционал

- Адаптивная навигация с бургер-меню
- Анимированная бегущая строка с логотипами клиентов
- Карточки кейсов/проектов
- Блок услуг (дизайн, разработка, копирайтинг)
- Футер с контактами и соцсетями

## 🚀 Запуск локально

```bash
git clone https://github.com/joyl-script/test-company.git
cd test-company
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000)

## ⚠️ Что стоит поправить перед показом работодателю

- В README сейчас указана ссылка на защищённый git-branch preview-деплой (`test-company-git-main-...vercel.app`) — замени на рабочую production-ссылку выше.
- Замени плейсхолдерные контакты (`+7 999 999 99 99`, `team@TestCompany.ru`) на реальные или пометь явно, что это макет без бэкенда.
- Убери из README личный номер телефона — публиковать его в открытом репозитории не стоит.
- В репозитории лежат `AGENTS.md`/`CLAUDE.md` — будь готова объяснить на собеседовании, какая часть кода писалась вручную, а какая — с помощью AI-ассистента.
